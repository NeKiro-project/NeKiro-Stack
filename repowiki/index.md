# NeKiro Stack RepoWiki

This is the bilingual reading surface for the immutable multi-component
assembly and product acceptance repository. The Stack README remains
canonical; MkDocs renders it in CI.

## Start here

- [Source documentation](source-docs/index.md) — manifest, preparation, Compose, and acceptance guidance.
- [GitHub repository](https://github.com/NeKiro-project/NeKiro-Stack) — source, issues, and releases.
- [Core RepoWiki](https://nekiro-project.github.io/NeKiro/) — platform contracts and architecture.

The Stack owns release pins and acceptance. It does not copy component
production source or silently change immutable revisions.
